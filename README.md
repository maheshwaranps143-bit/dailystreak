# DailyStreak 

A habit tracker web app where you can add daily habits, check them off each day, and watch your streaks grow. Includes a GitHub-style calendar heatmap so you can see your consistency at a glance.

## Features

- **Add / delete habits** — track whatever you want (reading, water, no sugar, etc.)
- **Daily check-off** — mark a habit done for today with one click
- **Streak tracking** — see your current streak and longest streak per habit
- **Calendar heatmap** — visualize completion history like GitHub's contribution graph
- **Habit categories** — organize habits (health, study, personal, etc.)
- **Clean, minimal UI**

## Tech Stack

- **Frontend:** React + Vite
- **Backend / Database:** Supabase (Postgres) for habits, completions, and auth
- **Hosting:** Vercel
